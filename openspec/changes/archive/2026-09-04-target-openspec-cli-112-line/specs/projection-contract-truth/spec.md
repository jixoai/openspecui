## MODIFIED Requirements

### Requirement: Static Projection Does Not Invent Line-Current Runtime Evidence

Static exports MAY include captured OpenSpecUI-12 compatibility or policy facts but SHALL NOT synthesize live
Schema resolution, archived validation, archive retirement, requirement diffs, batch status, validation
findings, or global Agent filesystem observations.

#### Scenario: Static archive evidence is absent

- **GIVEN** a static export contains no captured archived-validation result
- **WHEN** Change Evidence renders
- **THEN** it SHALL identify the evidence as unavailable in the static snapshot
- **AND** SHALL NOT display a fabricated pass, failure, root, or Agent repair state

#### Scenario: Static diff evidence is absent

- **GIVEN** a static export contains no captured requirement-diff payload
- **WHEN** Change Detail renders a MODIFIED delta
- **THEN** the delta SHALL present its captured local content only
- **AND** SHALL NOT display a locally recomputed diff or a fabricated upstream warning

#### Scenario: Static findings evidence is absent

- **GIVEN** a static export contains no captured validation-findings payload
- **WHEN** the validation evidence surface renders
- **THEN** it SHALL identify the findings evidence as unavailable in the static snapshot
- **AND** SHALL NOT display a fabricated findings document, informational item, or filtered count

### Requirement: Generator Evidence Follows the Admitted CLI

Agent generator evidence SHALL resolve the running OpenSpec CLI's live version and SHALL compare on-disk
generated state against the admitted 1.12 expectations. The pinned generator constant SHALL state the 1.12.0
baseline and SHALL never be substituted for a live resolution. Generated-by comparisons SHALL be series-aware:
artifacts generated by the admitted series SHALL NOT be flagged stale merely for differing from the pinned
baseline constant, while below-admitted or unparseable generators SHALL be stale.

#### Scenario: Live version is never fabricated

- **GIVEN** an Agent projection cannot resolve the running CLI version
- **WHEN** generator evidence is computed
- **THEN** the projection SHALL report unresolved evidence
- **AND** SHALL NOT present the pinned constant as the observed version

#### Scenario: Stale generated state is line-aware

- **GIVEN** on-disk Agent artifacts carry `generatedBy: 1.11.0` while the admitted CLI line is 1.12
- **WHEN** generator evidence is computed
- **THEN** the artifacts SHALL be reported as stale with the generator version as evidence
- **AND** artifacts generated by an admitted 1.12.x generator SHALL NOT be reported stale
