OpenSpec 规划拓扑速查

先找唯一可写 root，再叠加只读 References；Context 是推导结果，Workset 是个人视图。

Root selection

--store <id>
  > nearest real openspec/ root
  > config-only repo's store: pointer
  > error when registered stores make the target ambiguous
  > implicit cwd only when the command allows scaffolding

Relationship law

Term Shared Writable Purpose
Project root Git Yes Code repo planning
Store Git When selected Standalone planning
Reference config.yaml No External spec context
Context No, derived No Root plus references
Workset No, local N/A Open folders together
Reference 只接受注册 Store id；它不是任意项目规划根或 package 路径之间的边。store: 只在 config-only root 中作为可写根的 fallback，存在本地 planning shape 时会被忽略。 
default registry:
  Unix/macOS  ~/.local/share/openspec/stores/registry.yaml
  Windows     %LOCALAPPDATA%\openspec\stores\registry.yaml

override root for one environment:
  XDG_DATA_HOME=/isolated/data openspec store list
