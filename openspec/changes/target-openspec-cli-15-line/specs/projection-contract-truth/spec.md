## MODIFIED Requirements

### Requirement: Generator Evidence Follows the Admitted CLI

Generator staleness evidence SHALL follow the admitted OpenSpec CLI line: artifacts generated by the 1.15.0
pinned CLI baseline SHALL read as current for admitted 1.15.x sessions, artifacts generated by older lines
SHALL carry their historical generated-version evidence, and the pinned generator constant SHALL state the
1.15.0 baseline. A session running a retired CLI line SHALL NOT receive the v15 registry's staleness
interpretations for artifacts it did not generate.

#### Scenario: Staleness tracks the admitted line

- **GIVEN** Agent artifacts generated by the pinned 1.15.0 CLI in an admitted 1.15.x session
- **WHEN** tool init state is projected
- **THEN** the artifacts SHALL read current against the 1.15.0 pinned generator baseline
- **AND** artifacts generated by older lines SHALL retain their historical generated-version evidence and
  any staleness interpretation the admitted CLI owns
